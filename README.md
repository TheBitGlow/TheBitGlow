<br/>

**[InfoShield](https://github.com/TheBitGlow/InfoShield)** 是一款离线轻量化敏感信息脱敏桌面工具，基于 Python 3 与 PySide6 开发，专为保障企业与个人的数据安全与合规隐私而设计：

- 🔒 **100% 本地纯离线运行 (Zero Cloud Dependency)**  
  绝不联网、无需调用任何外部云端 API、零数据上传，从物理层杜绝数据外泄与合规风险，满足企业、金融与科研级严格保密需求。
- 🧠 **智能识别去标识化 (Smart De-Identification & Anonymization)**  
  - **实体智能脱敏**：针对机构、人员姓名、身份证、电话、行业等敏感字段按字数精细映射替换（最长受控不超 3 个 `×`）；
  - **数据度量脱敏**：精准识别数值、金额、人数、百分比（最长不超 2 个 `××`），并智能保留 `%`、`万元`、`人` 等核心语义度量单位；
  - **大纲序号独家保护**：全面守护中英文各级编号与多层章节结构（`一、`、`（一）`、`1.1.2` 等），结构完整保留，排版绝不误伤。
- 📑 **多格式文档原生结构解析**  
  原生支持 `.docx`（Word 段落与表格结构严密保持）、`.xlsx`（Excel 工作簿单元格）、`.csv`、`.md`、`.json`、`.txt` 原位解析与批处理。
- ⚡ **现代 Fluent 桌面工作台交互**  
  支持文件/文件夹拖拽直接投放与批量处理，提供实时脱敏前后双栏对照与精准统计指标，内置中英双语（i18n）一键无缝热切换。
